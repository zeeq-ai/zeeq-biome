Biome can work with the test framework you already use. Start with the core package; add the EF Core integration if your tests need to persist the graph.

## Requirements

- **.NET 10** and **C# 14** (the sugar methods use C# 14 `extension` blocks).
- Any test framework. The examples use [TUnit](https://tunit.dev).
- The core package has **no dependencies**.

## Add the packages

::code-group

```bash [dotnet CLI]
dotnet add package Zeeq.Biome
# Optional: save with a DbContext
dotnet add package Zeeq.Biome.EntityFrameworkCore
```

```xml [Tests.csproj] {6-7}
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Zeeq.Biome" Version="*" />
    <PackageReference Include="Zeeq.Biome.EntityFrameworkCore" Version="*" />
  </ItemGroup>
</Project>
```

```xml [Directory.Packages.props] {3-4}
<Project>
  <ItemGroup>
    <PackageVersion Include="Zeeq.Biome" Version="x.y.z" />
    <PackageVersion Include="Zeeq.Biome.EntityFrameworkCore" Version="x.y.z" />
  </ItemGroup>
</Project>
```

::

::note
Only add `Zeeq.Biome.EntityFrameworkCore` when you want to **save through a `DbContext`**. For pure unit tests, the core package alone is enough.
::

## Namespaces

```csharp [Usings.cs]
// Biome, Blueprint, Sequence, BiomeOptions, IBiomeStore, …
using Zeeq.Biome;
using Zeeq.Biome.EntityFrameworkCore;   // EfCoreStore, db.AsBiomeStore()
```

## Verify the install

To check the install before defining your app's blueprints, start a small session in a test. This example needs no store:

```csharp [InstallTests.cs] {6-7}
public sealed class InstallTests
{
    [Test]
    public async Task Biome_starts()
    {
        var biome = Biome.Start("seed", new BiomeOptions<string>());
        await biome.BuildAsync(); // NullStore: nothing is saved
    }
}
```

::tip
The minimal install above starts a session with a plain `string` as the seed. The [Quick start](/getting-started/quick-start) replaces it with a real seed and your own `TestBiome`.
::
