An **aggregate** is a result that implements `IBiomeAggregate`, so Biome saves its parts in place of the wrapper. You build one with an input blueprint: `Blueprint.FromInput`, where tests customize a small input object and the factory builds the related rows from it.

Input blueprints can build aggregates as well as ordinary entity outputs, so the full explanation, with a worked example, lives in one guide:

- [Aggregates: one input, several rows](/guides/input-blueprints#aggregates-one-input-several-rows) covers `IBiomeAggregate`, save-time expansion, and transient aggregates.
- [Input blueprints](/guides/input-blueprints) covers ordinary entity outputs and typed child inputs. Check that the package referenced by your project exposes the form you use.
