A **blueprint** is a `static readonly` value that knows how to build **one valid, uninteresting entity**. There are three kinds:

|Kind|Factory|Use for|
|---|---|---|
|`Blueprint<TSeed, T>`|`Blueprint.For<TSeed, T>(ctx => new() { … })`|A root entity|
|`ChildBlueprint<TSeed, TParent, T>`|`Blueprint.ChildOf<TSeed, TParent, T>((parent, ctx) => new() { … })`|An entity that belongs to a parent|
|`InputBlueprint<TSeed, TInput, T>`|`Blueprint.FromInput<TSeed, TInput, T>(() => new(), (input, ctx) => …)`|An [aggregate](/guides/aggregates) only|

## A root blueprint

::code-group

```csharp [Blueprints.cs] {7-8,11}
public static partial class Blueprints
{
    public static readonly Blueprint<ZeeqSeed, CodeRepository> Repository =
        Blueprint.For<ZeeqSeed, CodeRepository>(ctx =>
            new()
            {
                Id = ctx.NewId("repo"), // "repo_<uuidv7>"
                OrganizationId = ctx.Seed.Organization.Id,
                OwnerQualifiedName = "zeeq-ai/example",
                Enabled = true,
                CreatedAtUtc = ctx.Now, // never DateTimeOffset.UtcNow
            }
        );
}
```

::code-collapse{label="Without Biome" name="setup"}
```csharp
// A factory method in a helper class: no sequences, no clock, no parent wiring,
// and every test must remember to pass the right organization.
public static class TestData
{
    public static CodeRepository Repository(
        Organization organization,
        string? ownerQualifiedName = null,
        bool enabled = true,
        DateTimeOffset? createdAtUtc = null
    )
    {
        var now = DateTimeOffset.UtcNow;
        return new CodeRepository
        {
            Id = $"repo_{Guid.CreateVersion7():N}",
            OrganizationId = organization.Id,
            OwnerQualifiedName = ownerQualifiedName ?? "zeeq-ai/example",
            Enabled = enabled,
            CreatedAtUtc =
                createdAtUtc
                ?? new DateTimeOffset(now.Ticks - now.Ticks % 10, TimeSpan.Zero),
        };
    }
}
```
::

::

The factory receives a context (`ctx`):

|Member|Use|
|---|---|
|`ctx.Seed`|The baseline rows (organization, owner).|
|`ctx.Now`, `ctx.Ago(t)`, `ctx.FromNow(t)`|The session clock, already rounded.|
|`ctx.NewId("prefix")`|`prefix_<uuidv7>` unless options override it.|
|`ctx.Index`|Position in this Add. **Cosmetic values only.**|
|`ctx.Next(seq)`|Advance a sequence manually. Prefer `Derive(prop, seq)`.|
|`ctx.Ancestor<T>()`|Nearest ancestor of type `T`. Throws a clear error if none.|
|`ctx.All<T>()`, `ctx.Last<T>()`|Inspection only. Never for wiring relationships.|
|`ctx.Parent`, `ctx.ParentIndex`|Child context only.|

## Factory rules

1. ***Valid and uninteresting.*** Every required column gets a default no test should care about.
2. IDs come from `ctx.NewId("prefix")`. Time comes from `ctx.Now` / `ctx.Ago` / `ctx.FromNow`.
3. Take the parent from the typed argument, and grandparents from `ctx.Ancestor<T>()`.
4. **Leave derived properties unset**, so a [`Derive`](/guides/customizing#derived-defaults-are-fill-only) can fill them.
5. A property that tests vary must be **settable**.

::warning
`ctx.Last<T>()` and `ctx.All<T>()` are for inspection. **Do not wire relationships with them.** It breaks as soon as a test adds siblings or uses `.Under`. Use a child blueprint with its typed parent.
::

::caution
Customizers assign properties, so a property a test varies needs a setter. With `{ get; init; }` the compiler rejects the assignment (`CS8852`). `Derive` can still fill `init` properties.
::

## Blueprints are immutable values

Every modifier returns a **new** blueprint, so variants never change their base:

```csharp [Blueprints.cs] {4-5}
public static readonly Blueprint<ZeeqSeed, CodeRepository> Repository = /* … */;

// A variant: Repository itself is unchanged.
public static readonly Blueprint<ZeeqSeed, CodeRepository> DisabledRepository =
    Repository.With(Repositories.Disabled);
```

|Modifier|Effect|
|---|---|
|`.With(trait)`|Adds a trait. Runs before call-site customizers, so the call site still wins.|
|`.Derive(e => e.Prop, (e, ctx) => value)`|Fill-only assignment after customizers.|
|`.Derive(e => e.Prop, sequence)`|Fill-only assignment from a [sequence](/guides/sequences).|
|`.AsTransient()`|The output is built and returned, but never saved. See [Transients](/guides/transients).|

::note
Declare variants **below their base, in the same file**. Static fields initialize top to bottom, and across `partial` files the order is unspecified. The same goes for a sequence used by a blueprint.
::

## Adding blueprints to a chain

```csharp [CodeRepositoryTests.cs] {3}
await TestBiome
    .Start(out var seed)
    .AddOne(Blueprints.Repository, out var repo)
    .BuildAsync();
```

In real tests you rarely call `AddOne` directly. You write [four sugar one-liners](/guides/scenario-helpers-and-sugar) per type, and the chain becomes `.AddCodeRepository(out var repo)`.
